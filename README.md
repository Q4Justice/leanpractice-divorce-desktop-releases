updates only.

**Mac:** open the `.dmg` and drag the app into **Applications**, then open it from Applications.
The first time, macOS says it can't verify the app. Close that message, open **System Settings ›
Privacy & Security**, scroll down and choose **Open Anyway** next to "LeanPractice Divorce",
then enter your Mac password. You only do this once.

**Windows:** run the setup file. No administrator rights are needed. If Windows says it protected your
PC, choose **More info › Run anyway**.

Step-by-step instructions with screenshots, first-time setup and troubleshooting:
**[Installation guide](docs/INSTALL.md)**.

### What's new in 1.3.1

- New: Case documents, under the steps. Link the folder where you keep a client's bank statements, pay stubs
  and tax returns to the case. The app reads each file once (PDFs, including filled-in forms and scans,
  pictures, text and CSV files) and lists what it read, and anything it couldn't read and why. Your files are
  never moved or changed.
- The AI assistant can now answer questions from those documents. It searches the folder, opens only the pages
  it needs, and puts a link to the file and page next to each figure; click one to open the file. Above its
  answer it lists what it searched for and which pages it read, and it works out sums and averages exactly.
- The text read from the folder is kept with the case on this computer, so it isn't read again; only the pages
  the assistant opens are sent, with zero data retention. Unlinking the folder deletes that text. The link
  belongs to this computer: on another computer, link the folder again.

## Updates

The app checks this page for new versions. When one is available it shows a banner; choose
**Install and restart**. Your cases are saved and backed up first, and stay where they are.

## Your data

Cases are saved as files on your own computer (Documents › LeanPractice Cases unless you choose another
folder in Settings). Nothing is sent to this page.
