# LeanPractice MSA Worksheet: downloads

The desktop app for Florida uncontested dissolutions with children. This page holds the installers and
updates only.

## Download version 1.0.4

Released October 30, 2026. Choose the file for your computer:

| Computer | Download |
| --- | --- |
| Mac with Apple Silicon (M1 or later) | [LeanPractice.MSA.Worksheet_1.0.4_aarch64.dmg](https://github.com/Q4Justice/leanpractice-divorce-desktop-releases/releases/download/v1.0.4/LeanPractice.MSA.Worksheet_1.0.4_aarch64.dmg) |
| Mac with Intel | [LeanPractice.MSA.Worksheet_1.0.4_x64.dmg](https://github.com/Q4Justice/leanpractice-divorce-desktop-releases/releases/download/v1.0.4/LeanPractice.MSA.Worksheet_1.0.4_x64.dmg) |
| Windows 10 or 11 | [LeanPractice.MSA.Worksheet_1.0.4_x64-setup.exe](https://github.com/Q4Justice/leanpractice-divorce-desktop-releases/releases/download/v1.0.4/LeanPractice.MSA.Worksheet_1.0.4_x64-setup.exe) |

**Mac:** open the `.dmg` and drag the app into **Applications**, then open it from Applications.
The first time, macOS says it can't verify the app. Close that message, open **System Settings ›
Privacy & Security**, scroll down and choose **Open Anyway** next to "LeanPractice MSA Worksheet",
then enter your Mac password. You only do this once.

**Windows:** run the setup file. No administrator rights are needed. If Windows says it protected your
PC, choose **More info › Run anyway**.

### What's new in 1.0.4

- Dollar amounts you enter show a $ sign and cents, for example $ 1,250.00.

## Updates

The app checks this page for new versions. When one is available it shows a banner; choose
**Install and restart**. Your cases are saved and backed up first, and stay where they are.

## Your data

Cases are saved as files on your own computer (Documents › LeanPractice Cases unless you choose another
folder in Settings). Nothing is sent to this page.
